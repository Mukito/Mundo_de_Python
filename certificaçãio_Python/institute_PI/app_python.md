# Onde o Python é utilizado?
Você se lembra de Battlefield 2, Battlefield 2142 e Battlefield Heroes — jogos de estratégia e tiro em primeira pessoa da EA DICE? Todos eles utilizam Python para a lógica e o controle de servidores. O Python é frequentemente usado na criação de jogos gratuitos e de código aberto, como OpenRTS, PySol, Metin 2 ou Frets On Fire — jogos famosos no estilo Guitar Hero desenvolvidos com pygame.

E quanto aos grandes sites e serviços? Dropbox? Uber? Spotify? Pinterest? BuzzFeed? Sim. Todos eles foram desenvolvidos, em maior ou menor grau, utilizando Python. Outros exemplos?

  * Aplicações de Internet (BitTorrent, Jogger Publishing Assistant, TheCircle, TwistedMatrix)
  * CAD/CAM 3D (FreeCAD, Fandango, Blender, Vintech RCAM)
  * Aplicações Corporativas (Odoo, Tryton, Picalo, LinOTP 2, RESTx)
  * Aplicações de Imagem (Gnofract 4D, Gogh, imgSeek, MayaVi, VPython)
  * Aplicações Móveis (Aarlogic C05/3, AppBackup, Pyroute)
  * Aplicações de Escritório (calibre, faces, Notalon, pyspread)
  * Gerenciadores de Informações Pessoais (BitPim, Narval, Prioritise, Task Coach, WikidPad)
(Fonte: https://wiki.python.org/moin/PythonProjects)
