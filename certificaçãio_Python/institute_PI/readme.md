# Programa do Curso
### Neste curso, você aprenderá:

  * os conceitos universais de programação de computadores;
  * a sintaxe e a semântica da linguagem Python;
  * habilidades práticas para resolver desafios típicos de implementação;
  * como utilizar os elementos mais importantes da Biblioteca Padrão do Python;
  * como instalar o seu ambiente de execução;
  * como projetar, desenvolver, testar e depurar seus próprios programas em Python.

### O curso está dividido em 4 módulos:

  **1. Módulo 1**
    * Introdução ao Python e à programação de computadores;
  **2. Módulo 2**
    * Tipos de dados, variáveis, operações básicas de entrada e saída e operadores básicos;
  **3. Módulo 3**
    *  Valores booleanos, execução condicional, laços de repetição, listas e processamento de listas, operações lógicas e bit a bit;
  **Módulo 4**
    *  Funções, tuplas, dicionários, exceções e processamento de dados.
